# **App Name**: Not-ELFBEH

## Core Features:

- Note Creation: Allows users to create new Markdown notes easily with a dedicated input interface.
- Note Listing: Displays an organized list of all saved notes, enabling quick browsing and selection.
- Note Editing: Provides an interface to open and modify existing notes, reflecting changes in real-time.
- Note Deletion: Enables users to remove unwanted notes from their collection with a confirmation step.
- Local Note Storage: Persists all user-created notes securely on the device's local storage (e.g., AsyncStorage).
- Real-time Markdown Preview: Instantly renders Markdown syntax into a live, formatted text preview as the user types.

## Style Guidelines:

- Primary color: A calm and professional blue (#2970A3) to convey focus and clarity.
- Background color: A very light, almost white, blue-gray (#ECF2F5) to maintain a clean and readable interface.
- Accent color: A soft, refreshing aqua-cyan (#82C9C9) to highlight interactive elements and provide visual interest.
- Body and headline font: 'Inter', a modern sans-serif, chosen for its objectivity and high readability, perfect for a text-centric application.
- Minimalist and outline-style icons will be used for actions like 'add', 'edit', 'delete', and 'save', ensuring consistency and clarity.
- A clean and uncluttered layout, emphasizing ample whitespace to keep the focus on the note content, adapting responsively across devices.
- Subtle and fluid animations for transitions between note views and for feedback on user actions like saving or deleting a note.
