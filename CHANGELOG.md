
# Changelog

Tüm önemli değişiklikler bu dosyada belgelenecektir.

## [1.0.0] - 2024-05-22
### Eklendi
- **Firebase Auth:** Güvenli kullanıcı girişi ve kayıt sistemi.
- **AI Asistanı:** Not özetleme, iyileştirme ve başlık oluşturma özellikleri (Genkit entegrasyonu).
- **Docker Desteği:** Docker CLI ve Docker Compose yapılandırmaları.
- **PWA Altyapısı:** Mobil cihazlarda ana ekrana eklenebilme ve uygulama benzeri deneyim.
- **Real-time Sync:** Firestore üzerinden anlık not senkronizasyonu.
- **Güvenlik Kuralları:** Firestore Security Rules ile kullanıcı bazlı veri koruması.

### İyileştirmeler
- Markdown işleyici performans iyileştirmeleri.
- Mobil arayüz (Responsive) geliştirmeleri.
- Dokümantasyon ve kurulum rehberi profesyonelleştirildi.
